# Nimbus Weather

##### **Weather website template using WeatherAPI**

###### Nimbus is a weather web-app that you can use either locally by compiling the finder.go file or make a website using it (you will have to change some things in order to do this)


##### **Features**

* Search bar to get the location's weather that you want
* Auto guess weather
* Temperature with icons
* Sunrise and Sunset hours
* Windspeed and Rain chance percentage
* Weather alerts with severity and instructions
* State of the weather including quote and icon

##### **Installation**

  To install the weather website, you will need to get the finder.go to get the backend and the index.html + style.css + app.js to get the full website template
  You cannot get a fully compiled binary directly from the GitHub repo as the app relies on your own API key from WeatherAPI to function


##### **Technologies**

* Backend : Go
* Web UI: JS/HTML/CSS
* API: https://www.weatherapi.com/
* Images/Icons: Sources: {WeatherAPI / AutoDraw} Format: AVIF with PNG fallback
